# Basic C Calculator

A terminal-based calculator written in C that performs basic arithmetic operations, powers, roots, and modulus calculations.

## Description

This project is a simple command-line calculator developed using the C programming language. It allows users to perform basic arithmetic operations along with powers, square roots, cube roots, nth roots, and modulus calculations.

## How to Run It

### 1. Compile the program

Open a terminal in the project folder and run:

```bash
gcc basic-c-calculator.c -o calculator -lm
